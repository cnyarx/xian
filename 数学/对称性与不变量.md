# 对称性与不变量

对称性（对象经过某种变化后关键规律保持不变）是理论物理减少复杂度的核心工具，也是大模型研究中最值得迁移的方法论。

## 两个核心概念

- **等变**：$f(\rho_X(g)x) = \rho_Y(g)f(x)$ —— 先改变输入再计算，与先计算再按对应方式改变输出，结果相同；
- **不变**：$f(\rho_X(g)x) = f(x)$ —— 输入的写法虽然变了，但核心对象没变，模型输出也不应改变。

## 弦理论 → 大模型

1. 把明确对称性直接写进网络结构，减少模型需要重新学习的内容；
2. 解释模型时优先寻找换一种参数写法后仍保持不变的结构；
3. 在模型合并前先对齐神经元排列和表示基底；
4. 对科学问题使用符合旋转、置换、坐标变换或洛伦兹变换的网络。

## 大模型 → 弦理论

1. 自动寻找几何对象的离散对称性；
2. 从数据中提出候选对称变换；
3. 判断不同构造是否可能属于同一等价类；
4. 从大量构型中识别可能保持不变的量。
