# 中心荷

衡量每种量子场对世界面缩放对称性贡献大小的一个数，通常用 $c$ 表示。

## 为什么需要中心荷

量子化后，每种世界面场都会对缩放对称性产生影响。有些贡献为正，有些为负。全部贡献必须刚好抵消，否则理论会依赖人为选择的坐标网格。

## 各项贡献

| 场类型 | 中心荷 | 说明 |
|--------|--------|------|
| 每个坐标场 $X^\mu$ | $1$ | 来自 $T_X(z)T_X(w)$ 的四次方项系数 $1/2$ |
| 每个费米子场 $\psi^\mu$ | $1/2$ | 来自 $T_\psi(z)T_\psi(w)$ 的四次方项系数 $1/4$ |
| $bc$ 鬼场 | $-26$ | 权重 $\lambda=2$ 代入 $c_{bc} = -2(6\lambda^2-6\lambda+1)$ |
| $\beta\gamma$ 鬼场 | $+11$ | 权重 $\lambda=3/2$ 代入 $c_{\beta\gamma} = 2(6\lambda^2-6\lambda+1)$ |

## 总中心荷

$$c_{\text{总}} = D + \frac{D}{2} - 26 + 11 = \frac{3D}{2} - 15$$

要求 $c_{\text{总}} = 0$ 以消除 [[物理学/Weyl 反常|Weyl 反常]]，得到 $D = 10$。
