# 局部到整体

从局部规律构造全局结构，是概率论、几何和计算图中的共同问题。

## 概率链式法则

大语言模型的自回归生成使用：
$$p(x_{1:n}) = \prod_{i=1}^{n} p(x_i \mid x_{<i})$$

整段序列的概率等于每一步条件概率的乘积。

## 几何中的局部拼接

理论物理和几何也经常从局部信息构造整体：
- 局部坐标区域拼成完整流形；
- 局部相互作用产生整体相变；
- 局部张量连接形成整体相关结构；
- 局部满足方程还要检查不同区域连接处是否一致。

## 几何方法 → 大模型

1. 建立 token、句子、段落、章节和文档的分层一致性检查；
2. 不只评估单步预测，还检查局部结果能否拼成一致整体；
3. 研究小的单步误差怎样累积成长序列中的事实和逻辑错误；
4. 对不同上下文窗口重叠部分增加一致性约束。

## 大模型方法 → 弦理论

1. 生成局部几何表达和坐标转换候选；
2. 自动定位哪个局部区域导致整体条件失败；
3. 用程序检查区域之间的兼容性；
4. 从局部数值结果中提出整体结构猜想。
