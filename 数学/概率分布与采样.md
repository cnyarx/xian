# 概率分布与采样

从复杂概率分布中抽取样本，是统计物理和生成模型共有的核心数学工具。

## 能量形式

统计物理和许多生成模型使用能量形式表示概率分布：
$$p(x) = \frac{e^{-E(x)}}{Z}$$

能量 $E(x)$ 越低的状态通常越容易出现，$Z$ 用来把所有状态的可能性调整到总和为 1。

## 共同关心的问题

- 怎样从极其复杂的概率分布中抽取样本；
- 怎样让候选样本更接近目标分布；
- 怎样校正模型提出但不完全正确的样本；
- 怎样判断采样是否遗漏重要区域。

## 理论物理方法 → 大模型

1. 把模型输出看作候选提案，而不是最终真值；
2. 使用独立验证器接受或拒绝候选；
3. 对生成偏差做重要性校正；
4. 用有效样本数而不是表面样本量评价生成质量。

## 大模型方法 → 弦理论

1. 按条件生成通量、几何或 D-brane 候选；
2. 从历史计算中学习更有效的提案分布；
3. 自动调用约束程序筛选候选；
4. 对同构、对偶和对称相关结果进行去重。
