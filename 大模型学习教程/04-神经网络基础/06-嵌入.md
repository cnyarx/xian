# 嵌入

## 一句话定义

嵌入（Embedding）把离散对象的编号映射成可训练的连续向量，使模型能用数学运算处理词、商品或用户。

## 为什么编号不够

若把“猫、狗、汽车”编码为 `0、1、2`，数字距离会误导模型：汽车并不比狗更“大一倍”。编号只用于查找，不能直接表示意义。

嵌入矩阵：

$$E\in\mathbb{R}^{V\times d}$$

- $V$：词表大小。
- $d$：嵌入维度。
- 第 $i$ 行 $E_i$：编号为 $i$ 的 token 向量。

若 $V=50000,d=4096$，矩阵有约 2.048 亿个参数。

## 查表过程

```text
token "猫" → ID 42 → 取嵌入矩阵第42行 → [0.18, -0.42, ...]
```

PyTorch：

```python
import torch
import torch.nn as nn

embedding = nn.Embedding(num_embeddings=1000, embedding_dim=64)
token_ids = torch.tensor([10, 25, 10])
vectors = embedding(token_ids)
print(vectors.shape)  # [3, 64]
```

相同 ID 得到同一基础向量，但经过注意力层后，会因上下文得到不同隐藏表示。

## 嵌入如何学会语义

训练下一个 token 时，反向传播会更新嵌入矩阵。用法相似的词经常出现在相似上下文，向量逐渐形成可用于预测的关系。但单个维度通常没有简单稳定的中文含义，概念常分布在许多维度上。

## 输入嵌入与输出权重

语言模型最后要把隐藏向量映射回词表分数。许多模型共享输入嵌入矩阵和输出矩阵，这叫权重绑定（Weight Tying），可减少参数并改善部分模型表现。

## 常见误区

- 嵌入向量不是字典定义，而是为训练目标学出的数字表示。
- 向量接近通常表示模型使用方式接近，不保证人类语义完全相同。
- 嵌入维度是计算特征数，不是现实空间维度。
