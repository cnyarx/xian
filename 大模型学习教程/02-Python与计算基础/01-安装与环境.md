# 安装与环境

## 目标

完成本篇后，你能运行 Python 程序，知道 `python`、`pip`、虚拟环境和 Jupyter 分别做什么。

## 四个核心概念

- **Python**：一种编程语言；我们用文字写指令，Python 解释器负责执行。
- **解释器（Interpreter）**：逐步读取并执行 Python 代码的程序。
- **pip**：Python 的包安装工具，用来安装 NumPy、PyTorch 等别人写好的功能。
- **虚拟环境（Virtual Environment）**：项目专属的软件包房间，防止不同项目要求的版本互相冲突。
- **Jupyter Notebook**：把代码分成小格逐格运行的交互式文档，适合学习和实验。

## 安装检查

在终端输入：

```bash
python --version
```

如果系统使用 `python3`：

```bash
python3 --version
```

看到类似 `Python 3.11.9` 就说明解释器可用。版本号由“主版本.次版本.修订版本”组成。

## 创建虚拟环境

```bash
python -m venv .venv
```

这条命令在当前目录建立 `.venv`，里面保存该项目自己的 Python 和软件包。

Linux/macOS 激活：

```bash
source .venv/bin/activate
```

Windows PowerShell 激活：

```powershell
.venv\Scripts\Activate.ps1
```

激活后安装学习工具：

```bash
python -m pip install numpy jupyter torch
```

这里：

- `python -m pip` 表示让当前 Python 运行 pip；
- `install` 表示安装；
- 后面是软件包名。

> [!warning]
> PyTorch 是否能使用 GPU，取决于操作系统、显卡和安装版本。学习前几章只用 CPU 也足够。正式安装应以 PyTorch 官方安装选择器为准。

## 第一个程序

创建 `hello.py`：

```python
name = "大模型学习者"
print("你好，" + name)
```

运行：

```bash
python hello.py
```

预期输出：

```text
你好，大模型学习者
```

## 启动 Jupyter

```bash
jupyter notebook
```

浏览器会打开文件列表。新建 Python Notebook，在单元格中输入：

```python
2 + 3
```

运行后得到 `5`。

## 常见错误

- `command not found`：Python 未安装，或命令名是 `python3`。
- `No module named ...`：当前环境没有安装这个包。
- 安装后仍找不到包：很可能安装软件包和运行代码用了不同 Python；优先使用 `python -m pip`。
- 不要把真实密码、Token、API Key 写进 Notebook 或提交到仓库。
