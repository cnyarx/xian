# 缩放点积注意力

## 完整公式

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}+M\right)V$$

## 逐部分拆解

设序列长 $n$，每个头的维度为 $d_k$：

- $Q\in\mathbb{R}^{n\times d_k}$：每个位置的查询向量。
- $K\in\mathbb{R}^{n\times d_k}$：每个位置的键向量。
- $V\in\mathbb{R}^{n\times d_v}$：每个位置携带的内容。
- $K^T$：把 K 行列互换。
- $QK^T\in\mathbb{R}^{n\times n}$：每个 Query 与每个 Key 的匹配分数。
- $d_k$：Key 向量维度。
- $M$：掩码；不允许看的位置加入极大负数。

## 第一步：点积匹配

对 Query $q_i$ 和 Key $k_j$，先计算原始点积：

$$r_{ij}=q_i\cdot k_j$$

点积大，通常表示方向更一致、匹配程度更高。

## 第二步：为什么除以 $\sqrt{d_k}$

若各分量均值约 0、方差约 1，$d_k$ 项乘积相加后的方差约为 $d_k$。维度大时分数绝对值变大，softmax 会过度尖锐，梯度变小。除以 $\sqrt{d_k}$ 后方差回到约 1 的量级。

这是统计尺度控制，不是凭经验随便加的常数。

## 第三步：掩码

Decoder-only 模型不能看到未来 token。掩码矩阵示意：

$$M=\begin{bmatrix}0&-\infty&-\infty\\0&0&-\infty\\0&0&0\end{bmatrix}$$

softmax 后，$-\infty$ 对应权重为 0。

## 第四步：softmax

先把缩放和掩码合并到最终分数：

$$
s_{ij}=\frac{r_{ij}}{\sqrt{d_k}}+M_{ij}
$$

再对每一行做 softmax：

$$a_{ij}=\frac{e^{s_{ij}}}{\sum_l e^{s_{il}}}$$

每行权重非负且和为 1；被掩码的位置因 $M_{ij}$ 为极大负数而得到接近 0 的权重。

## 第五步：加权汇总

$$o_i=\sum_j a_{ij}v_j$$

输出是所有 Value 的加权平均。

## 一个两词例子

假设某 Query 对两个 Key 的缩放后分数是 `[2, 0]`：

```text
softmax([2,0]) ≈ [0.881, 0.119]
V1=[1,0], V2=[0,2]
输出=0.881×[1,0]+0.119×[0,2]=[0.881,0.238]
```

## 计算复杂度

$QK^T$ 产生 $n\times n$ 矩阵，标准注意力时间和注意力矩阵存储大致随 $n^2$ 增长。序列长度翻倍，相关部分成本约变为四倍。
