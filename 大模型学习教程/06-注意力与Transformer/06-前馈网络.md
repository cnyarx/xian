# 前馈网络

## 一句话定义

Transformer 的前馈网络（Feed-Forward Network，FFN）对每个 token 独立执行同一组非线性变换。注意力在 token 之间传递信息，FFN 在单个 token 内加工特征。

## 经典 FFN

$$\operatorname{FFN}(x)=W_2\phi(W_1x+b_1)+b_2$$

通常先从模型维度 $d_{model}$ 扩展到更大的中间维度 $d_{ff}$，再压回：

```text
4096 → 11008或16384 → 4096
```

扩展空间让网络能表示更多非线性组合。

## 每个位置共享参数

同一层中所有 token 使用相同 $W_1,W_2$，但输入向量不同，所以输出不同。FFN 不直接混合不同位置；位置间信息已由注意力写入各 token 向量。

## GLU

门控线性单元（Gated Linear Unit）用一个分支生成内容，另一个分支充当门：

$$\operatorname{GLU}(x)=(xW_a)\odot\sigma(xW_b)$$

门值决定每个特征通过多少。

## SwiGLU

SwiGLU 用 SiLU/Swish 作为门控激活：

$$\operatorname{SwiGLU}(x)=\operatorname{SiLU}(xW_g)\odot(xW_u)$$

完整输出再乘下降投影：

$$y=W_d\left[\operatorname{SiLU}(W_gx)\odot(W_ux)\right]$$

许多现代 LLM 使用 SwiGLU，但具体中间维度和偏置设置因模型而异。

## 参数量

经典无偏置 FFN 大约有：

$$d_{model}d_{ff}+d_{ff}d_{model}=2d_{model}d_{ff}$$

SwiGLU 有三个投影，约 $3d_{model}d_{ff}$。设计者通常相应调整 $d_{ff}$，使总参数预算可比。

## 常见误区

- FFN 不是“可有可无的小层”；它通常占 Transformer 很大比例参数。
- FFN 在各位置独立，不代表它不含上下文；输入已经经过注意力。
- 中间维度越大不一定越好，还受参数和计算预算限制。
