# 位置编码

## 为什么需要位置

自注意力只比较向量内容。如果不加入位置信息，“猫追狗”和“狗追猫”只含相同 token，模型无法仅靠无位置信息的注意力区分顺序。

位置编码（Positional Encoding）把 token 在序列中的位置告诉模型。

## 正弦位置编码

原始 Transformer 使用固定的正弦和余弦函数：

$$PE_{(pos,2i)}=\sin\left(pos/10000^{2i/d}\right)$$
$$PE_{(pos,2i+1)}=\cos\left(pos/10000^{2i/d}\right)$$

- $pos$：token 位置。
- $i$：向量维度编号的一半。
- $d$：模型维度。
- 偶数维用正弦，奇数维用余弦。

不同维度使用不同波长，像许多转速不同的钟表共同编码位置。位置向量与 token 嵌入相加。

## 可学习绝对位置嵌入

为每个位置直接训练一个向量：

$$h_{pos}=E_{token}+E_{position}$$

简单有效，但超出训练最大位置时没有现成向量，需要扩展或插值。

## RoPE

旋转位置嵌入（Rotary Position Embedding，RoPE）不把位置向量直接相加，而是按位置旋转 Query 和 Key 的二维分量对。

二维旋转矩阵：

$$R(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$$

位置 $m$ 的向量乘 $R(m\theta)$。两个位置的点积会自然包含相对位置差 $m-n$，因此 RoPE 兼顾绝对位置操作与相对位置信息。RoPE 是许多公开 decoder-only 模型采用的位置方法之一 `[C]`；是否采用及其参数必须以具体模型配置为准。

## ALiBi

ALiBi（Attention with Linear Biases）不改变向量，而是在注意力分数中加入与距离有关的线性负偏置：

$$s_{ij}=q_i\cdot k_j-m_h|i-j|$$

距离越远，默认惩罚越大；每个注意力头使用不同斜率 $m_h$。

## 长上下文不是只换位置编码

把位置编码扩展到更远，并不自动保证模型能有效使用长上下文。训练数据长度、注意力模式、计算资源和评测方法都会影响真实能力。
