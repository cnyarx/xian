# 什么是机器学习

## 一句话定义

机器学习是让计算机从数据中自动发现规律，而不是由人把每条规则都提前写好。

## 传统编程 vs 机器学习

传统编程：

```
输入 → 人写的规则 → 输出
```

机器学习：

```
输入 + 期望输出 → 机器自己学规则 → 输出
```

大模型是机器学习的极端例子：不写对话规则，只给海量文本，让模型自己学说话方式。

## 三大范式

### 监督学习

每种输入都有正确答案。模型学习输入到输出的映射。

```
训练数据：猫的照片→"猫"，狗的照片→"狗"
模型学到：怎样从照片判断是猫还是狗
```

**大模型中的体现**：预训练时，每个 token 的正确答案就是文档中的下一个 token。

### 无监督学习

只有输入没有标签。模型自己发现数据中的模式。

```
数据：用户的购物记录
模型发现：买了尿布的人常常也买啤酒
```

**大模型中的体现**：纯粹的无监督学习在现代大模型中较少使用，通常结合自监督任务。

### 自监督学习

输入本身提供监督信号，不需要人工标注。

```
数据：一段文本
任务：预测下一个词
监督信号：文本中实际出现的下一个词
```

**大模型中的体现**：这是大模型预训练的核心范式。从原始文本中自动构造训练信号。

### 强化学习

模型在环境中做出决策，通过奖励信号学习优化行为。

```
模型：玩游戏
行动：向左、向右
奖励：得分
学习：选择能得高分的行动
```

**大模型中的体现**：RLHF（从人类反馈中学习）是强化学习在语言模型中的应用。

## 训练、验证、测试

数据通常分成三份：

- **训练集（Training Set）**：用来学习模型参数。
- **验证集（Validation Set）**：用来调整超参数，检测过拟合。
- **测试集（Test Set）**：只在训练完成后用一次，评估最终性能。

**为什么不能混用**：如果在测试集上调参，测试集就不再是客观的评估标准。

## 常见误区

- 机器学习不是魔法：模型只会从数据中学习统计规律，不会真正“理解”。
- 更多数据不总是更好：垃圾数据只能训练出垃圾模型。
- 训练集准确率高不代表模型好：可能只是记住了训练数据（过拟合）。
