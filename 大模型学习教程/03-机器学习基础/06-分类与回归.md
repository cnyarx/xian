# 分类与回归

## 一句话定义

**回归**预测一个连续数值。**分类**预测一个类别标签。

## 回归

输出是连续数值。

```
例子：
- 预测房价 → 输出 350 万
- 预测明天温度 → 输出 25.3°C
- 预测股票价格 → 输出 128.5
```

常用损失函数：MSE。

## 分类

输出是离散类别。

### 二分类

只有两个类别。

```
例子：
- 邮件是垃圾邮件还是正常邮件 → 输出 [0 或 1]
- 图片是猫还是狗 → 输出 [猫, 狗]
```

### 多分类

有三个或更多类别。

```
例子：
- 识别手写数字 → 输出 [0, 1, 2, ..., 9]
- 大模型预测下一个词 → 输出 [词表中任意 token]
```

## softmax

softmax 把任意实数向量变成概率分布。

$$
\text{softmax}(x_i) = \frac{e^{x_i}}{\sum_{j} e^{x_j}}
$$

**数值例子**：

```
输入 logits: [2.0, 1.0, 0.1]

Step 1: exp  → [7.39, 2.72, 1.11]
Step 2: sum  → 11.22
Step 3: /sum → [0.66, 0.24, 0.10]
```

所有输出概率之和为 1。softmax 不影响大小顺序，但把原始分数映射到了可解释的概率空间。

## 在大模型中的角色

大模型的输出层通常是 softmax 作用在词表维度上。模型为每个可能的下一个 token 输出一个概率，然后从概率分布中采样生成文本。

## 分类 vs 回归

| 特性 | 回归 | 分类 |
|---|---:|---|
| 输出 | 连续数值 | 离散类别 |
| 损失函数 | MSE、MAE | 交叉熵 |
| 输出层 | 线性层 | 线性层 + softmax |
| 评估 | R²、RMSE | 准确率、F1 分数 |

## 常见误区

- 分类的输出不是"哪个类别"，而是"每个类别的概率"。
- softmax 不改变大小顺序，只做归一化。
- 有些问题看起来像分类，实际上更适合回归（如评分预测）。
