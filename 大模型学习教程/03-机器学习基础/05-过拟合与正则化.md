# 过拟合与正则化

## 一句话定义

**过拟合**是模型记住了训练数据中的噪声和偶然规律，而不是学到真正的通用规律。

## 过拟合 vs 欠拟合

```
欠拟合：模型太简单，训练集和测试集表现都差。
过拟合：模型太复杂，训练集表现极好但测试集表现差。
```

**生活类比**：学生死记硬背练习题答案，换一道同类型的新题就不会了。

**在大模型中的体现**：模型可能“记住”了训练数据中的特定句子，但推理时不能泛化到新问题。

## 怎样检测过拟合

```
训练损失持续下降，验证损失开始上升 → 过拟合
```

## 正则化

正则化是防止过拟合的技术。

### L2 正则化

在损失函数中加入参数大小的惩罚项：

$$
L_{\text{total}} = L_{\text{original}} + \lambda \sum \|\theta\|^2
$$

- $\lambda$：正则化系数，控制惩罚强度。
- 鼓励参数保持较小值，减少模型复杂度。

### Dropout

训练时随机丢弃一部分神经元，迫使网络不依赖少数特定神经元。

```python
dropout = nn.Dropout(p=0.5)
```

- `p=0.5`：每个神经元有 50% 概率在本步被临时关闭。
- 测试时 Dropout 自动关闭，所有神经元都参与。

### 早停

当验证损失不再下降时停止训练，防止继续训练导致过拟合。

### 数据增强

从现有数据生成更多训练样本，增加数据多样性，减少过拟合。

## 在大模型中的应用

- 大模型训练常使用 Weight Decay（权重衰减）。在普通 SGD 等特定更新条件下，它可与 L2 正则化等价；在 Adam 等自适应优化器中，两者通常不等价，AdamW 会把权重衰减与梯度自适应缩放解耦。
- Dropout 在 Transformer 中有一定使用，但现代大模型有时省略。
- 模型规模很大时是否过拟合取决于数据量、重复度、训练步数和任务，不能只凭参数量判断。

## 常见误区

- 正则化不能完全替代足够多的数据。
- 训练损失低不等于模型好。
- 过拟合不一定意味着模型太复杂，也可能数据太少或数据质量差。
