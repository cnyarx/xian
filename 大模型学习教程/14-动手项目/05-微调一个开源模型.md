# 微调一个开源模型

## 目标

使用来源和许可证已核验的官方开放权重模型，通过 LoRA 完成一个可复查的小规模指令微调流程：

```text
核验模型 → 准备 JSONL → 训练/验证切分
→ 构造模板 → 只对回答计算损失
→ 注入 LoRA → 训练与验证 → 保存适配器和元数据
```

## 已核验的教学示例

本项目默认使用：

```text
EleutherAI/pythia-70m
```

EleutherAI 官方 Pythia 仓库和论文记录了该系列的开放训练研究用途；具体 checkpoint 的最终许可证与文件以官方模型卡为准：https://huggingface.co/EleutherAI/pythia-70m

Pythia-70M 是 Base 模型，不是聊天模型。因此本教程使用明确的普通文本模板，不声称它自带聊天模板。它很小，适合走通流程，不代表微调后会获得实用对话质量。

模型卡和远程 revision 可能变化。正式实验应把核验过的 commit hash 作为 `MODEL_REVISION`，而不是长期依赖浮动的 `main`。

## 环境与验证边界

需要 Python 3.10+，以及兼容版本的：

```text
torch
transformers
peft
accelerate
```

安装 PyTorch 时应根据 CPU/CUDA 使用官方命令：https://pytorch.org/get-started/locally/

然后安装其余库，例如：

```bash
python -m pip install "transformers>=4.46,<6" "peft>=0.13,<1" "accelerate>=1,<2"
```

依赖范围用于减少 API 漂移，不是已在所有组合上验证的锁文件。当前知识库所在机器有 `transformers 5.8.0`，但缺少 PyTorch、PEFT 和 Accelerate，因此本项目未在本机执行训练；代码只做语法检查。真正运行后应把 `pip freeze` 保存到实验目录。

## 数据格式

建立 `train.jsonl` 和 `validation.jsonl`，每行一个 JSON 对象：

```json
{"instruction":"把这句话改得更礼貌：快点回复","response":"方便时请尽快回复，谢谢。"}
{"instruction":"把这句话改得更礼貌：你写错了","response":"这里可能有一处需要核对，方便再检查一下吗？"}
```

训练集和验证集不要含重复或近重复样本。不得放入密钥、隐私、无权使用的数据或无法核验的错误答案。

## 固定测试指令

建立 `test_instructions.txt`，每行一条未出现在训练集或验证集中的指令：

```text
把这句话改得更礼貌：这份表格今天给我
把这句话改得更礼貌：你的说明我没看懂
把这句话改得更礼貌：重新检查后再发
```

程序会在训练前后用相同的贪心解码设置生成回答，并保存到 `lora_adapter/test_outputs.json`。这些输出用于观察行为变化，不应被重新加入训练集。

## 标签掩码为什么重要

模板为：

```text
### Instruction:
{instruction}

### Response:
{response}<eos>
```

模型输入包含指令和回答，但训练目标只对回答部分计算损失。指令位置的标签设为 `-100`，PyTorch 交叉熵会忽略这些位置。否则模型还会被训练去复述固定模板和用户指令。

## 完整单文件程序

保存为 `train_lora.py`：

```python
import argparse
import json
import os
import random
from pathlib import Path

import torch
from peft import LoraConfig, get_peft_model
from torch.utils.data import DataLoader, Dataset
from transformers import AutoModelForCausalLM, AutoTokenizer, get_linear_schedule_with_warmup


class InstructionDataset(Dataset):
    def __init__(self, path, tokenizer, max_length):
        self.examples = []
        for line_number, line in enumerate(Path(path).read_text(encoding="utf-8").splitlines(), 1):
            if not line.strip():
                continue
            item = json.loads(line)
            instruction = item["instruction"].strip()
            response = item["response"].strip()
            if not instruction or not response:
                raise ValueError(f"empty field at {path}:{line_number}")
            self.examples.append(
                encode_example(instruction, response, tokenizer, max_length)
            )
        if not self.examples:
            raise ValueError(f"no examples in {path}")

    def __len__(self):
        return len(self.examples)

    def __getitem__(self, index):
        return self.examples[index]


def set_seed(seed):
    random.seed(seed)
    torch.manual_seed(seed)
    if torch.cuda.is_available():
        torch.cuda.manual_seed_all(seed)


def format_prompt(instruction):
    return f"### Instruction:\n{instruction}\n\n### Response:\n"


def encode_example(instruction, response, tokenizer, max_length):
    prompt_ids = tokenizer(format_prompt(instruction), add_special_tokens=True)["input_ids"]
    answer_ids = tokenizer(response + tokenizer.eos_token, add_special_tokens=False)["input_ids"]
    input_ids = (prompt_ids + answer_ids)[:max_length]
    prompt_length = min(len(prompt_ids), len(input_ids))
    labels = [-100] * prompt_length + input_ids[prompt_length:]
    if all(label == -100 for label in labels):
        raise ValueError("max_length removed the complete answer")
    return {"input_ids": input_ids, "labels": labels}


def make_collator(pad_token_id):
    def collate(batch):
        max_length = max(len(item["input_ids"]) for item in batch)
        input_ids, labels, attention_mask = [], [], []
        for item in batch:
            padding = max_length - len(item["input_ids"])
            input_ids.append(item["input_ids"] + [pad_token_id] * padding)
            labels.append(item["labels"] + [-100] * padding)
            attention_mask.append([1] * len(item["input_ids"]) + [0] * padding)
        return {
            "input_ids": torch.tensor(input_ids, dtype=torch.long),
            "labels": torch.tensor(labels, dtype=torch.long),
            "attention_mask": torch.tensor(attention_mask, dtype=torch.long),
        }
    return collate


def find_lora_targets(model):
    preferred = ["query_key_value", "q_proj", "k_proj", "v_proj", "o_proj"]
    linear_suffixes = {
        name.rsplit(".", 1)[-1]
        for name, module in model.named_modules()
        if isinstance(module, torch.nn.Linear)
    }
    targets = [name for name in preferred if name in linear_suffixes]
    if not targets:
        raise ValueError(
            "No known attention projection was found. Inspect model.named_modules() "
            "and set target_modules for the verified architecture."
        )
    return targets


@torch.no_grad()
def evaluate(model, loader, device):
    model.eval()
    losses = []
    for batch in loader:
        batch = {key: value.to(device) for key, value in batch.items()}
        output = model(**batch)
        losses.append(output.loss.item())
    model.train()
    return sum(losses) / len(losses)


@torch.no_grad()
def generate_outputs(model, tokenizer, instructions, device, max_new_tokens):
    model.eval()
    outputs = []
    for instruction in instructions:
        encoded = tokenizer(format_prompt(instruction), return_tensors="pt")
        encoded = {key: value.to(device) for key, value in encoded.items()}
        generated = model.generate(
            **encoded,
            do_sample=False,
            max_new_tokens=max_new_tokens,
            pad_token_id=tokenizer.pad_token_id,
            eos_token_id=tokenizer.eos_token_id,
        )
        prompt_length = encoded["input_ids"].shape[1]
        answer = tokenizer.decode(
            generated[0, prompt_length:], skip_special_tokens=True
        ).strip()
        outputs.append({"instruction": instruction, "output": answer})
    model.train()
    return outputs


def load_test_instructions(path):
    instructions = []
    for line_number, line in enumerate(
        Path(path).read_text(encoding="utf-8").splitlines(), 1
    ):
        instruction = line.strip()
        if instruction:
            instructions.append(instruction)
    if not instructions:
        raise ValueError(f"no test instructions in {path}")
    return instructions


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--model-id", default="EleutherAI/pythia-70m")
    parser.add_argument("--revision", required=True)
    parser.add_argument("--train", default="train.jsonl")
    parser.add_argument("--validation", default="validation.jsonl")
    parser.add_argument("--test-instructions", default="test_instructions.txt")
    parser.add_argument("--output", default="lora_adapter")
    parser.add_argument("--max-length", type=int, default=256)
    parser.add_argument("--max-new-tokens", type=int, default=64)
    parser.add_argument("--batch-size", type=int, default=4)
    parser.add_argument("--epochs", type=int, default=3)
    parser.add_argument("--learning-rate", type=float, default=2e-4)
    parser.add_argument("--seed", type=int, default=7)
    args = parser.parse_args()

    if not os.environ.get("MODEL_LICENSE_CHECK"):
        raise SystemExit("MODEL_LICENSE_CHECK must record the verified license source and date")
    set_seed(args.seed)
    test_instructions = load_test_instructions(args.test_instructions)

    tokenizer = AutoTokenizer.from_pretrained(args.model_id, revision=args.revision)
    if tokenizer.eos_token is None:
        raise ValueError("tokenizer must define eos_token")
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token

    model = AutoModelForCausalLM.from_pretrained(args.model_id, revision=args.revision)
    model.config.use_cache = False
    targets = find_lora_targets(model)
    config = LoraConfig(
        r=8,
        lora_alpha=16,
        lora_dropout=0.05,
        target_modules=targets,
        bias="none",
        task_type="CAUSAL_LM",
    )
    model = get_peft_model(model, config)
    model.print_trainable_parameters()

    device = "cuda" if torch.cuda.is_available() else "cpu"
    model.to(device)

    train_dataset = InstructionDataset(args.train, tokenizer, args.max_length)
    validation_dataset = InstructionDataset(args.validation, tokenizer, args.max_length)
    collator = make_collator(tokenizer.pad_token_id)
    train_loader = DataLoader(
        train_dataset, batch_size=args.batch_size, shuffle=True, collate_fn=collator
    )
    validation_loader = DataLoader(
        validation_dataset, batch_size=args.batch_size, shuffle=False, collate_fn=collator
    )

    optimizer = torch.optim.AdamW(model.parameters(), lr=args.learning_rate)
    total_steps = args.epochs * len(train_loader)
    scheduler = get_linear_schedule_with_warmup(
        optimizer,
        num_warmup_steps=max(1, int(0.05 * total_steps)),
        num_training_steps=total_steps,
    )

    before = evaluate(model, validation_loader, device)
    print("validation loss before training:", round(before, 4))
    outputs_before = generate_outputs(
        model, tokenizer, test_instructions, device, args.max_new_tokens
    )

    global_step = 0
    for epoch in range(args.epochs):
        model.train()
        for batch in train_loader:
            batch = {key: value.to(device) for key, value in batch.items()}
            output = model(**batch)
            output.loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()
            scheduler.step()
            optimizer.zero_grad(set_to_none=True)
            global_step += 1
        validation_loss = evaluate(model, validation_loader, device)
        print(
            f"epoch {epoch + 1} | step {global_step} | "
            f"validation loss {validation_loss:.4f}"
        )

    output_dir = Path(args.output)
    model.save_pretrained(output_dir)
    tokenizer.save_pretrained(output_dir)
    outputs_after = generate_outputs(
        model, tokenizer, test_instructions, device, args.max_new_tokens
    )
    (output_dir / "test_outputs.json").write_text(
        json.dumps(
            {"before": outputs_before, "after": outputs_after},
            ensure_ascii=False,
            indent=2,
        ),
        encoding="utf-8",
    )
    metadata = {
        "base_model_id": args.model_id,
        "base_model_revision": args.revision,
        "target_modules": targets,
        "train_file": str(Path(args.train).resolve()),
        "validation_file": str(Path(args.validation).resolve()),
        "test_instructions_file": str(Path(args.test_instructions).resolve()),
        "seed": args.seed,
        "epochs": args.epochs,
        "batch_size": args.batch_size,
        "learning_rate": args.learning_rate,
        "transformers_version": __import__("transformers").__version__,
        "peft_version": __import__("peft").__version__,
        "torch_version": torch.__version__,
        "license_check": os.environ["MODEL_LICENSE_CHECK"],
    }
    (output_dir / "training_metadata.json").write_text(
        json.dumps(metadata, ensure_ascii=False, indent=2), encoding="utf-8"
    )
    print("adapter saved to:", output_dir)


if __name__ == "__main__":
    main()
```

## 运行

先在能够访问 Hugging Face 的环境中读取官方 API 返回的当前精确 commit SHA，并核验模型卡许可证。下面命令不把 `main` 当作可复现 revision；若 API 不可访问、没有返回 `sha` 或许可证无法确认，应停止实验：

```bash
export MODEL_REVISION="$(python - <<'PY'
import json
from urllib.request import urlopen

url = "https://huggingface.co/api/models/EleutherAI/pythia-70m"
with urlopen(url, timeout=30) as response:
    metadata = json.load(response)
revision = metadata.get("sha")
if not revision:
    raise SystemExit("model API did not return an immutable sha")
print(revision)
PY
)"
export MODEL_LICENSE_CHECK="verified from the official Pythia-70M model card; record the actual date and license text in the experiment log"
python train_lora.py \
  --model-id EleutherAI/pythia-70m \
  --revision "$MODEL_REVISION" \
  --train train.jsonl \
  --validation validation.jsonl \
  --test-instructions test_instructions.txt \
  --output lora_adapter \
  --seed 7
```

运行后还要把模型卡许可证文本、核验日期、`MODEL_REVISION` 和 `pip freeze` 一起保存到实验记录。本教程写作环境在核验时无法连接 Hugging Face，因此不把未经真实 API 验证的 SHA 写死在文档里；可复现性由运行时获取并保存不可变 SHA 保证。

## 换成聊天模型时

若替换其他模型，应先检查：

1. 官方模型卡和许可证；
2. tokenizer 是否定义 `chat_template`；
3. 官方推荐的 `apply_chat_template` 用法；
4. 目标层名称；
5. 最大长度和显存；
6. Base、Instruct 与 Chat checkpoint 的区别。

不能把本教程的 Pythia 文本模板自动套给所有聊天模型。聊天模型应优先使用发布者提供的模板。

## 验收

- `print_trainable_parameters()` 显示可训练参数远小于总参数；
- 检查第一条样本中指令和 padding 的 label 都是 `-100`；
- 训练前后都运行验证集，不只看训练 loss；
- 固定一组未参与训练的测试指令，程序保存相同解码设置下的 `test_outputs.json`，逐条比较微调前后输出；
- 检查回答是否过拟合模板或泄漏训练样本；
- `lora_adapter/` 中包含适配器、tokenizer、`training_metadata.json` 和 `test_outputs.json`；
- 元数据记录基础模型 ID、不可变 revision、库版本、随机种子和许可证核验。

小验证集 loss 下降不等于通用能力提高。还要检查事实性、安全和原有能力是否退化。

## 常见失败

- 找不到 target module：打印 `model.named_modules()`，按官方架构确认，不盲猜；
- 回答没有 loss：`max_length` 截断了完整回答；
- padding 参与 loss：collator 没把 padding label 设为 `-100`；
- 显存不足：减小 batch、长度或模型；量化需另行核验 QLoRA 依赖；
- 输出只复述指令：检查标签掩码和数据模板；
- 验证 loss 上升：过拟合、数据问题或学习率不合适。
