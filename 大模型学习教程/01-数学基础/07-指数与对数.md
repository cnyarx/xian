# 指数与对数

## 一句话定义

当指数是正整数时，**乘方**（Exponentiation）$a^n$ 表示把底数 $a$ 连乘 $n$ 次；把指数扩展到零、负数、分数和一般实数后，$a^x$ 由保持指数运算规律的数学定义给出。**对数**（Logarithm）是指数运算的逆运算：它问“底数取多少次方才得到目标数？”

---

## 为什么需要它

指数和对数在大模型中无处不在：

- **softmax** 把模型输出转换成概率，核心就是指数运算
- **交叉熵损失** 的核心是取对数
- **注意力机制** 中的缩放和 softmax 都依赖指数
- **学习率调度** 常使用指数衰减
- **缩放定律** 用对数坐标来展示

---

## 指数与乘方

### 从正整数指数开始

当指数是正整数时，乘方就是“同一个底数连续相乘”：

```
2³ = 2 × 2 × 2 = 8
2⁴ = 2 × 2 × 2 × 2 = 16
2⁵ = 2 × 2 × 2 × 2 × 2 = 32
```

### 正整数指数的定义与扩展

对正整数 $n$：

$$
a^n = \underbrace{a \times a \times \cdots \times a}_{n \text{ 个 }a}
$$

为了保持 $a^{x+y}=a^x a^y$ 等运算规律，可以继续定义：

$$
a^0=1,\qquad a^{-n}=\frac{1}{a^n}\quad(a\ne0)
$$

对正底数 $a>0$，实数指数可用指数函数和自然对数定义：

$$
a^x=\exp(x\ln a)
$$

这个定义覆盖整数、分数、无理数等实数指数。例如 $4^{1/2}=2$，而 $2^{\sqrt2}$ 不能解释成“乘 $\sqrt2$ 次”，但仍有明确的实数值。

**每个符号在说什么：**
- $a$：底数（Base）；
- $x$ 或 $n$：指数（Exponent）；
- $a^x$：乘方的结果；
- $\exp$ 和 $\ln$：互为逆运算的指数函数与自然对数。

### 指数函数

**指数函数**一般写作 $f(x)=a^x$，其中 $a>0$ 且 $a\ne1$。以 $e$（自然常数 ≈ 2.71828）为底的：

$$
f(x) = e^x = \exp(x)
$$

称为自然指数函数。

**$e$ 是什么？**

$e$ 是一个特殊的数，约等于 2.71828。它的特殊之处在于：$e^x$ 的导数等于它自己。

```
d/dx(e^x) = e^x
```

这意味着 $e^x$ 在任何点的变化速度都等于它当前的值。这个性质让它在数学和物理中极其重要。

### 指数函数的性质

1. **增长极快**：$e^1 ≈ 2.7$，$e^2 ≈ 7.4$，$e^3 ≈ 20.1$，$e^{10} ≈ 22026$
2. **永远为正**：$e^x > 0$ 对所有 $x$ 成立
3. **$e^0 = 1$**：更一般地，对任意非零底数 $a$，都有 $a^0=1$；$0^0$ 不能由这条规则直接定义
4. **$e^{-x} = 1/e^x$**：负指数等于倒数

### 在大模型中的核心角色

**softmax 函数**：把任意实数向量变成概率分布。

$$
\text{softmax}(x_i) = \frac{e^{x_i}}{\sum_{j} e^{x_j}}
$$

**每个符号在说什么：**
- $x_i$：模型输出的原始分数（logit）
- $e^{x_i}$：对每个分数取指数，确保所有值都为正
- $\sum_j e^{x_j}$：所有指数值的和，用于归一化
- 结果：每个值都在 0 到 1 之间，且总和为 1

**数值例子：**

```
原始分数: [2.0, 1.0, 0.1]

Step 1: 取指数
e^2.0 = 7.389
e^1.0 = 2.718
e^0.1 = 1.105

Step 2: 求和
7.389 + 2.718 + 1.105 = 11.212

Step 3: 归一化
7.389 / 11.212 = 0.659  ← 第一个词的概率
2.718 / 11.212 = 0.242  ← 第二个词的概率
1.105 / 11.212 = 0.099  ← 第三个词的概率
```

**为什么用指数？**

- 确保所有概率为正（$e^x > 0$）
- 让分数高的项概率显著更高（指数放大差异）
- 数学上求导很方便

## 对数

### 直觉理解

**对数**回答这个问题："$a$ 要乘自己几次才能得到 $b$？"

$$
\log_2 8 = 3 \quad \text{因为} \quad 2^3 = 8
$$

$$
\log_{10} 100 = 2 \quad \text{因为} \quad 10^2 = 100
$$

### 严格定义

如果 $a^c = b$，那么 $\log_a b = c$。

对数是指数的**逆运算**。

### 常用对数

| 符号 | 底数 | 名称 | 使用场景 |
|---|---:|---|---|
| $\log_2 x$ | 2 | 二进制对数 | 信息论（比特） |
| $\log_{10} x$ | 10 | 常用对数 | 科学计数 |
| $\ln x$ | $e$ | 自然对数 | 数学、物理、机器学习 |
| $\log x$ | 不写底数 | 在机器学习中通常指 $\ln x$ | 论文中常见 |

### 对数的重要性质

1. **$\ln(ab) = \ln a + \ln b$**（乘法变加法）
2. **$\ln(a/b) = \ln a - \ln b$**（除法变减法）
3. **$\ln(a^n) = n \ln a$**（指数变乘法）
4. **$\ln(1) = 0$**（因为 $e^0 = 1$）
5. **$\ln(e) = 1$**（因为 $e^1 = e$）
6. **$\ln(x) < 0$ 当 $0 < x < 1$**（小数的对数）

### 在大模型中的核心角色

**交叉熵损失**：

$$
L = -\log P(\text{正确答案})
$$

**每个符号在说什么：**
- $P(\text{正确答案})$：模型给正确答案的概率
- $-\log$：取对数再加负号

**为什么用对数？**

- 概率在 0 到 1 之间，$\log$ 在 $(0, 1]$ 区间为负或零
- $-\log(0.01) = 4.6$（概率很小 → 惩罚很大）
- $-\log(0.99) = 0.01$（概率很大 → 惩罚很小）
- 对数把乘法变成了加法，让梯度计算更稳定

### 数值例子

```
模型预测正确答案的概率 = 0.1  → loss = -ln(0.1) = 2.30 （惩罚大）
模型预测正确答案的概率 = 0.5  → loss = -ln(0.5) = 0.69 （惩罚中等）
模型预测正确答案的概率 = 0.9  → loss = -ln(0.9) = 0.11 （惩罚小）
```

## 指数与对数的关系

```
指数：e^x    → 输入 x，输出 e^x
对数：ln x   → 输入 x，输出 ln x

它们互为逆运算：
ln(e^x) = x
e^{ln x} = x
```

```
指数增长得很快 → 对数增长得很慢

x:      1    10    100   1000
e^x:    2.7  22026 巨大   巨大
ln x:   0    2.3   4.6   6.9
```

## 缩放定律中的对数

缩放定律（Scaling Laws）常用双对数坐标，因为模型规模、数据量、计算量和损失可能跨越多个数量级。若两个正数变量满足幂律：

$$
y=Cx^a
$$

两边取对数得到：

$$
\log y=a\log x+\log C
$$

因此幂律在横轴为 $\log x$、纵轴为 $\log y$ 的 **log-log 图**上表现为直线，斜率是 $a$。这不同于通常所说的指数关系 $y=Ce^{ax}$：后者是在只对纵轴取对数的 **semi-log 图**上变成直线。

---

## 常见误区

1. **$\ln x$ 不是 $\log_{10} x$**
   在机器学习论文中，$\log$ 通常指 $\ln$（自然对数），不是 $\log_{10}$。

2. **$e^x$ 不是 $x^e$**
   $e^x$ 是指数函数（底数固定，指数变化），$x^e$ 是幂函数（指数固定，底数变化）。完全不同。

3. **$\ln(0)$ 没有定义**
   当 $x$ 从正数一侧趋近 0 时，$\ln x$ 趋向 $-\infty$；不能把 $\ln(0)$ 当作一个普通实数值。在精确实数数学中，有限 logits 的 softmax 分子都为正；但浮点程序仍可能因下溢得到数值 0，所以实现应使用减最大值或 `log_softmax` 等稳定方法。

4. **指数不是"增长很快"的代名词**
   指数函数确实增长很快，但"指数增长"在日常语言中常被滥用。在数学中，指数增长特指 $a^x$ 这种形式。
