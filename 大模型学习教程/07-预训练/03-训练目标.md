# 训练目标

## 因果语言建模

Decoder-only 模型通常最小化下一个 token 的平均负对数似然：

$$L=-\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(x_i\mid x_{<i})$$

若正确 token 概率高，损失小；概率低，损失大。完整符号和边界见 [[../16-公式手册/13-语言模型损失与困惑度公式|语言模型损失与困惑度公式]]。

### 单个 token 的数值例子

若正确 token 的模型概率为 0.8，损失是：

$$
-\ln(0.8)\approx0.223
$$

若概率为 0.1：

$$
-\ln(0.1)\approx2.303
$$

后者惩罚更大。训练不是只看 top-1 是否猜对，而是调整整个词表概率，使真实 token 的概率提高。

### 哪些位置参与平均

$N$ 应是实际参与损失的 token 数。padding、被掩码的提示部分或无效位置通常不计入分母。若两次实验对掩码和分母定义不同，平均 loss 不能直接比较。

## 右移目标

输入序列为：

```text
[我, 喜欢, 学习, 模型]
```

训练配对可理解为：

```text
输入: [我, 喜欢, 学习]
目标: [喜欢, 学习, 模型]
```

实际 Transformer 可一次并行计算所有位置，但因果掩码保证位置 $i$ 看不到未来目标。

## 困惑度

困惑度（Perplexity，PPL）是平均负对数损失的指数：

$$\operatorname{PPL}=e^L$$

若使用自然对数。直觉上，PPL 可粗略理解为模型每一步像在多少个同等可能候选中犹豫。例如 $L=\ln 10$ 时 PPL=10。

这个类比在真实非均匀分布中只是直觉，不代表每一步真的有 10 个等概率候选。

## 比较限制

困惑度只有在 tokenizer、数据集、文本预处理、掩码和计算方式一致时才适合直接比较。不同词表切分会改变 token 数和每 token 损失。

例子：同一句英文，一个 tokenizer 切成 5 个 token，另一个切成 8 个 token。即使两个模型给整句相似概率，每 token loss 和 PPL 也可能不同。

还应区分验证集与训练集。训练 PPL 很低可能只是过拟合，不能代表新文本表现。

## Masked Language Modeling

BERT 类 encoder 随机遮住部分 token，让模型根据左右上下文恢复。它不是从左到右生成目标；decoder-only LLM 通常使用因果语言建模。

例如：

```text
巴黎是法国的 [MASK]。
```

模型可同时利用“法国的”和句末信息预测“首都”。这与只能看左侧 token 的因果目标不同。

## 多目标训练

模型可增加代码填空、多模态匹配、检索或工具使用目标。若总损失为：

$$
L_{total}=\lambda_1L_{text}+\lambda_2L_{code}
$$

$\lambda_1,\lambda_2$ 决定两个目标的相对训练权重。损失数值尺度不同，权重相同也不保证梯度贡献相同，因此需要实验和梯度监控。

## 标签泄漏与数据错误

- 因果掩码错误会让位置看到未来答案，得到虚假的低损失；
- padding 未正确忽略会训练模型预测填充符；
- 聊天微调若不区分用户和助手 token，训练目标可能与预期不一致；
- 训练集和验证集重复会让验证 PPL 偏低。

## 怎样验收训练目标

1. 用极小序列手算单 token 损失；
2. 检查 logits、labels 和 mask 形状；
3. 修改未来 token，确认过去 logits 不变；
4. 统计实际参与损失的 token 数；
5. 与随机基线 $\ln(V)$ 的数量级比较；
6. 分开报告训练和验证损失。

## 练习

1. 正确 token 概率为 0.8 和 0.1 时，哪个损失更大？
2. 损失为 2 时计算 PPL。
3. 为什么不同 tokenizer 的 PPL 不能直接比较？
4. 比较因果语言建模和遮蔽语言建模。
