# 预训练概览

## 什么是预训练

预训练（Pre-training）让随机初始化的模型在大规模数据上优化预先规定的训练目标，学习语言和数据中的统计规律。不同架构使用不同目标：Decoder-only 自回归模型通常预测下一个 token；BERT 类模型可预测被遮蔽 token；T5 类模型可重建被遮蔽的文本片段。

本教程后续主要讨论 Decoder-only 大语言模型，因此下面以 next-token prediction（下一个 token 预测）为主。完成后得到的模型通常称为基础模型（Base Model）。

## 一条样本怎样训练

文本 `我喜欢学习` 被编码为 `[我, 喜欢, 学习]`：

```text
输入：我       → 目标：喜欢
输入：我 喜欢  → 目标：学习
```

模型输出词表概率，交叉熵衡量正确 token 的概率：

$$L=-\frac1T\sum_{t=1}^{T}\log P_\theta(x_t\mid x_{<t})$$

参数经反向传播和优化器更新。

## 完整流程

1. 收集并许可数据。
2. 清洗、去重、过滤、配比。
3. 训练 tokenizer。
4. 初始化模型参数。
5. 将 token 组成固定长度训练序列。
6. 多设备并行前向、反向和更新。
7. 定期保存检查点并在验证集评估。
8. 训练完成后做能力、安全和记忆风险评测。

## 预训练学到什么

为降低预测损失，模型会捕捉语法、词义、文本格式、代码模式、知识共现和部分可用于推理的模式。但预训练目标不保证事实可靠、价值对齐或指令遵循，这些需要后训练和外部验证。

## 继续预训练

Continued Pre-training（继续预训练）从已有基础模型出发，继续使用与该模型架构兼容的预训练目标，常用于领域、语言或长上下文适配。对于本教程聚焦的 Decoder-only 模型，它通常仍采用下一个 token 预测；对于 BERT、T5 等架构，则可继续使用遮蔽预测或片段重建。继续预训练不等于指令微调。
