# 04-神经网络基础答案

## [[../04-神经网络基础/01-神经元与感知机|01-神经元与感知机]]

1. $z=2(0.5)+1(-1)+0.2=0.2$。
2. 若输出规则为 $z\ge0$ 输出 1，可取 $w=[1,1]$、$b=-1.5$；只有输入 $(1,1)$ 时为正。
3. XOR 的四点为 $(0,0)\to0,(0,1)\to1,(1,0)\to1,(1,1)\to0$。两个正类位于对角，无法用一条直线把它们与另两个点完全分开。
4. 偏置平移决策边界或激活阈值；没有偏置，线性边界必须经过原点。

## [[../04-神经网络基础/02-激活函数|02-激活函数]]

1. ReLU 输出依次为 $0,0,2$。
2. $W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)$，仍是一次仿射变换。
3. Sigmoid 在绝对值很大时接近 0 或 1，导数接近 0，反向传播的梯度会被连续缩小。
4. ReLU 在 0 处有折角，负侧为 0，计算简单；GELU 平滑地按输入大小门控，负值也可保留少量输出，计算更复杂。优劣取决于架构和实验。

## [[../04-神经网络基础/03-多层感知机|03-多层感知机]]

1. $W_1x+b_1=[1-2,\ 4+1]=[-1,5]$；ReLU 后 $h=[0,5]$；最终 $y=W_2h+b_2=2\times0-1\times5+1=-4$。
2. $W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)$，仍是一次仿射变换。
3. 不一定。代价至少包括更多参数与显存、更多计算与通信；有限数据下还可能增加过拟合和调参难度。
4. 注意力让不同 token 位置交换和聚合信息；MLP/FFN 对每个位置独立做非线性特征变换。

## [[../04-神经网络基础/04-反向传播|04-反向传播]]

1. $dy/dx=2(2x+1)\times2=4(2x+1)$，$x=3$ 时为 $28$。
2. 计算图：$w,x\to m=wx$；$m,y\to e=m-y$；$e\to L=e^2$。反向梯度为 $\partial L/\partial e=2e$、$\partial e/\partial m=1$、$\partial m/\partial w=x$。
3. 局部导数往往依赖前向输入或输出，例如平方导数需要 $e$，激活导数需要激活前值；保存它们可避免全部重算，代价是显存。
4. 若每层局部导数绝对值长期小于 1，连乘后会迅速接近 0；饱和 sigmoid/tanh 容易出现这种情况。残差、归一化和合适初始化可缓解，但原因不只激活函数一个。

## [[../04-神经网络基础/05-优化器|05-优化器]]

1. $\theta_1=5-0.1\times2=4.8$；第二步使用新参数，$\theta_2=4.8-0.1\times(-1)=4.9$。
2. 动量累计过去方向；狭长谷底两侧交替梯度会互相抵消，而沿谷底一致方向会累积，从而减少左右摆动。
3. 二阶矩是梯度平方的移动平均。某参数历史梯度尺度大，分母就大、有效步幅变小；尺度小则相对步幅变大。
4. Adam 的自适应缩放会改变“把 L2 梯度加进原梯度”的实际衰减；AdamW 直接对参数施加与该缩放解耦的衰减，所以更新轨迹一般不同。

## [[../04-神经网络基础/06-嵌入|06-嵌入]]

1. $32000\times2048=65,536,000$ 个参数；若与输出层权重共享，不应重复计同一矩阵。
2. ID 只是类别编号。把 9 当连续数会错误暗示它比 3“大三倍”或彼此有固定距离；嵌入让每个 ID 学习独立向量。
3. 查表得到的输入嵌入通常相同（再加位置等信息后可不同）；经过上下文化层后会因周围 token 和位置不同而不同。
4. `emb = torch.nn.Embedding(20, 8); ids=torch.tensor([1,5,9]); out=emb(ids)`，输出形状为 `[3,8]`。
