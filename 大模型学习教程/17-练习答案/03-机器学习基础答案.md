# 03-机器学习基础答案

## [[../03-机器学习基础/01-什么是机器学习|01-什么是机器学习]]

1. 垃圾邮件分类：输入邮件内容，输出垃圾/正常；房价预测：输入房屋属性，输出价格；语音识别：输入音频，输出文字。
2. 自监督学习从数据自身构造监督目标，如遮住词再预测；无监督学习通常没有人为标签或这种明确预测目标，寻找聚类、密度或潜在结构。术语边界在文献中可能有重叠。
3. 训练集表现会被优化过程直接利用，容易过度乐观；验证集用于选择超参数和模型，测试集只用于最后评估。
4. 例如调节室温：状态是当前温度、时间和占用情况；行动是提高、降低或保持设定温度；奖励综合舒适度与能耗。

## [[../03-机器学习基础/02-数据与特征|02-数据与特征]]

1. 历次成绩、出勤、作业完成率、学习时长、课程难度。应注意隐私、因果混淆和数据是否在预测时可获得。
2. 一个常见起点是 800/100/100，但应按时间、用户或群组防止泄漏；小数据还可使用交叉验证。没有对所有任务唯一正确的比例。
3. 用测试集调参会把测试信息泄漏进模型选择，使最终成绩偏高。
4. 自回归预训练的输入是前文 token，标签是每个位置的下一个 token；严格说原始文本经过 tokenizer 后才形成这些训练对。

## [[../03-机器学习基础/03-损失函数|03-损失函数]]

1. 误差平方均为 1，MSE 为 $(1+1+1)/3=1$。
2. 若用自然对数，$-\ln0.3\approx1.204$。
3. 变小为 $-\ln0.8\approx0.223$，因为给正确类别的概率更高。
4. MSE 没有自然对应分类概率的对数似然，且在常见 softmax/sigmoid 输出饱和时梯度性质通常不如交叉熵。它并非数学上“绝对不能”用于分类，只是常见概率分类中交叉熵更匹配建模目标。

## [[../03-机器学习基础/04-梯度下降|04-梯度下降]]

1. $f'(x)=2x$。更新 $x'=x-0.5(2x)=0$，第一步后为 0，后两步仍为 0。
2. `0.1` 可能稳定但较慢；`2.0` 对 $x^2$ 的更新为 $x'=-3x$，会在两侧跳动且绝对值发散。实际结果还取决于损失曲率。
3. 批量梯度下降用全部训练样本算一次梯度；小批量每次只用一部分，计算更适合硬件并带有采样噪声。
4. Adam 会按参数历史梯度的一阶、二阶矩自适应调节步幅，常让早期优化更稳。但“更适合”是经验结论，不代表所有模型和预算下都优于精心调参的 SGD。

## [[../03-机器学习基础/05-过拟合与正则化|05-过拟合与正则化]]

1. 过拟合像背下练习题答案却不会做新题；欠拟合像连练习题规律也没学会。
2. 很可能严重过拟合，也要检查训练/验证预处理、标签、分布和损失口径是否一致。
3. 训练时随机丢弃并按实现规则缩放；测试时通常关闭随机丢弃，使用完整网络。
4. 大模型通常使用巨大且多样的数据、权重共享和正则化，并可能处于双下降等现代过参数化条件中；但它们仍会记忆、数据泄漏或对小型微调集过拟合，不能说天然不会过拟合。

## [[../03-机器学习基础/06-分类与回归|06-分类与回归]]

1. 是否下雨：分类；降雨量：回归；物体识别：分类；评分若只允许固定星级可作有序分类，若预测连续期望分数可作回归，取决于任务定义。
2. 减去最大值后算 $[1,e^{-2},e^{-2.8}]$，归一化约为 $[0.8360,0.1131,0.0508]$。
3. 交叉熵对应分类分布的负对数似然，直接奖励提高正确类别概率；MSE 更自然地对应带高斯误差的连续值预测。
4. 二分类可用一个 logit 加 sigmoid，也可用两个 logits 加 softmax；多分类通常用每类一个 logit 加 softmax。标签、损失函数与输出形式必须一致。
