# 07-预训练答案

## [[../07-预训练/01-预训练概览|01-预训练概览]]

1. 例如“我爱学习”切为 `[我,爱,学习]`，输入 `[我,爱]`，目标 `[爱,学习]`；长序列按每个位置右移构造。
2. 预训练主要学习续写数据分布；指令只是文本中的一种模式，模型没有被稳定训练为“识别请求并给理想回答”。
3. 预训练通常从随机或早期初始化开始学习通用数据；继续预训练从已有模型出发，在新领域或新增通用数据上继续同类目标。
4. 训练数据已直接影响参数，在其上测到的损失会偏乐观；需要独立验证数据观察泛化和过拟合。

## [[../07-预训练/02-训练数据|02-训练数据]]

1. 去重删除相同或近似重复样本；去污染移除与评测集或不该进入训练的数据重叠。一个样本可不重复却仍污染评测。
2. 重复样本获得更多训练权重，模型更可能逐字记住其中内容，尤其是罕见隐私或独特字符串。
3. 示例：中文 45%、英文 35%、代码 20%，目标是兼顾中文能力、英文知识覆盖和编程；真实配比应依据目标用户、质量、tokenizer 和消融实验，不存在通用最佳比例。
4. 可能误删讨论、教育和防御所需内容，造成领域盲区或群体差异；过滤器本身也可能有偏见。应记录规则并分组评测副作用。

## [[../07-预训练/03-训练目标|03-训练目标]]

1. 概率 0.1 的损失更大：$-\ln0.8\approx0.223$，$-\ln0.1\approx2.303$。
2. $\operatorname{PPL}=e^2\approx7.389$。
3. tokenizer 改变 token 粒度、序列长度和平均单位；“每 token 损失”不再是同一种测量单位。
4. 因果语言建模只看左侧预测下一个 token，适合自回归生成；遮蔽语言建模把部分 token 遮住，并利用左右上下文恢复，常用于双向表示学习。

## [[../07-预训练/04-缩放定律|04-缩放定律]]

1. 若幂律项为 $N^{-\alpha}$，$N$ 变 4 倍且 $\alpha=0.5$，该项乘 $4^{-0.5}=1/2$。
2. $6ND=6\times10^9\times2\times10^{10}=1.2\times10^{20}$ 次浮点运算的粗估。
3. 指数和系数从有限实验数据拟合，并依赖模型、数据和训练范围；超出观测范围可能失效。
4. 计算花在更多参数上后，每个参数看到的数据不足，模型可能没有被充分训练；在同一计算预算下，更小模型配更多高质量 token 可能损失更低。

## [[../07-预训练/05-训练稳定性|05-训练稳定性]]

1. 当 $\|g\|\le c$，乘数为 1；当梯度范数超过 $c$，整体按 $c/\|g\|$ 缩小到范数 $c$，方向不变。
2. FP16 有更高尾数精度但指数范围较窄，较易上溢/下溢；BF16 指数范围接近 FP32，但尾数更少。硬件支持与算子实现也影响选择。
3. 检查原始批次、学习率与调度、梯度范数、数值溢出、数据异常、损失缩放、节点通信和代码/配置变更，不能只凭曲线猜原因。
4. 无缝恢复还需要优化器矩、学习率调度器、随机数状态、数据迭代位置、混合精度 scaler 和分布式分片元数据等。
