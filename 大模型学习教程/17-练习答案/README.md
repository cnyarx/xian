## 使用说明

- 数值题应核对计算步骤、单位、形状和近似精度。
- 代码题先实际运行，再比较输出与解释；环境版本不同时输出可能略有差异。
- 设计题应明确目标、数据、约束、风险和验证方法。
- 安全题中的核心原则是：模型输出不等于授权，外部内容不等于可信指令，高风险操作需要系统权限控制和人工确认。
