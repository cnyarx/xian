# 11-部署与优化答案

## [[../11-部署与优化/01-模型量化|01-模型量化]]

1. 只算权重位数，4-bit 是 16-bit 的 $1/4$，理论上少 75%，或称压缩 4 倍。实际文件还含尺度、零点、元数据和未量化张量。
2. $q=\operatorname{round}(0.26/0.1)+0=3$；$\hat x=0.1(3-0)=0.3$。假设普通四舍五入且未触及整数上下界。
3. PTQ 在训练后校准/量化，不重新做完整量化感知训练；QAT 在训练中模拟量化误差，让权重适应低精度，成本更高。
4. GGUF 是容器格式，可存不同数据类型、量化方案和元数据；量化算法是如何把数值映射到低精度表示的方法。

## [[../11-部署与优化/02-模型服务|02-模型服务]]

1. 静态批处理常等最慢请求结束；连续批处理在请求完成时立即补入新请求，提高设备利用率并减少空槽。
2. 它减少为不同长度、动态增长 KV cache 预留连续大块造成的碎片和浪费。
3. 更大批次通常提高吞吐，但排队和每步处理时间可能增大；服务需按首 token 延迟、逐 token 延迟和吞吐目标调度。
4. 瓶颈可能在不支持该格式的内核、反量化、KV cache、CPU、通信或小批量调度；低位宽文件更小不保证硬件执行更快。

## [[../11-部署与优化/03-本地部署|03-本地部署]]

1. 只算 80 亿权重：FP16 为 $8\times10^9\times2=16$ GB（十进制），约 14.9 GiB；4-bit 为 4 GB，约 3.73 GiB。运行还需量化元数据、KV cache、激活、框架和系统内存，所以这是下限。
2. 本地部署：隐私和离线控制强，但需硬件、维护和安全配置；云 API：启动快、弹性和模型选择多，但有持续费用、网络和数据治理约束。
3. 还应看许可证、质量、上下文长度、tokenizer、量化支持、KV cache、吞吐、硬件兼容和任务评测。
4. 强认证与授权、TLS、限流、输入输出审计和隐私策略；最小权限运行、隔离工具和文件访问、及时更新依赖，并设置防火墙而非直接暴露默认端口。
