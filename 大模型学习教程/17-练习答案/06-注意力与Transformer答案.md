# 06-注意力与Transformer答案

## [[../06-注意力与Transformer/01-注意力直觉|01-注意力直觉]]

1. Query 是读者正在寻找的主题，Key 是每本书的索引标签，Value 是书中真正取出的内容；匹配 Query 与 Key 后按匹配程度汇总 Value。
2. “它”可能强烈关注“手机”，因为昂贵直接描述手机；也可能间接利用“苹果公司”确定语境。具体注意力由模型和层头决定，不能只凭句子断言唯一连接。
3. Query、Key、Value 都由同一序列的表示产生，序列内部的位置彼此关注。
4. 任意两个位置可在一层直接建立联系；标准全注意力要构造 $T\times T$ 分数矩阵，时间和内存随长度近似二次增长。

## [[../06-注意力与Transformer/02-缩放点积注意力|02-缩放点积注意力]]

1. $K^T=\begin{bmatrix}1&0\\1&1\end{bmatrix}$，所以 $QK^T=\begin{bmatrix}1&0\\2&1\end{bmatrix}$。若继续计算注意力，还应除以 $\sqrt{d_k}$、加掩码，再逐行做 softmax。
2. $\sqrt{64}=8$，所以分数除以 8。
3. 掩码位置若加 0，仍可能得到正概率；加极大负数后 softmax 概率趋近 0。
4. 从 $2048^2$ 增为 $4096^2$，元素数变 4 倍。

## [[../06-注意力与Transformer/03-多头注意力|03-多头注意力]]

1. $768/12=64$。
2. 每个头有独立的 Q/K/V 投影参数，训练后可形成不同子空间和匹配模式，不是复制同一结果。
3. 若总模型维度固定，各头维度随头数反比变化；合起来的 Q/K/V 投影仍常为 $D\times D$ 量级。
4. 注意力模式随输入、层和训练变化；相关性可分布在多个头，单个可视化也不能证明因果功能。

## [[../06-注意力与Transformer/04-位置编码|04-位置编码]]

1. 没有位置信息时，自注意力对输入位置的置换具有相应对称性，无法仅靠 token 内容稳定区分“狗咬人”和“人咬狗”的顺序。
2. 固定正弦编码无额外学习参数，并有规则结构；可学习嵌入更灵活但只直接训练已见位置，外推未必可靠。真实长上下文表现还取决于完整训练设置。
3. RoPE 把每对维度按位置角度旋转；两个位置的 Q、K 点积会依赖角度差，因此自然带入相对位移信息。
4. ALiBi 给注意力分数加入随距离增大的负偏置，所以其他条件相同时远处 token 分数更低。

## [[../06-注意力与Transformer/05-残差连接与层归一化|05-残差连接与层归一化]]

1. 均值为 2；按总体方差定义，方差为 $[(1-2)^2+0+(3-2)^2]/3=2/3$。若使用样本方差分母为 2，则为 1；LayerNorm 使用总体式分母 $d$。
2. $y=x+F(x)$ 的导数包含一条恒等路径，使梯度可直接传回，不必全部穿过复杂子层。
3. LayerNorm 减均值并除标准差，再做仿射变换；RMSNorm 不减均值，只按均方根缩放，参数和计算更少。
4. 数据流：$x\to\text{Norm}\to\text{Attention}\to+ x\to h\to\text{Norm}\to\text{FFN}\to+h\to y$。

## [[../06-注意力与Transformer/06-前馈网络|06-前馈网络]]

1. 两个矩阵参数为 $512\times2048+2048\times512=2,097,152$。
2. 注意力跨位置混合信息；FFN 在每个位置内部变换特征。
3. 门控让一条投影控制另一条投影哪些通道通过，形成输入相关的乘性交互，表达比单一路径更灵活。
4. $x$ 分别进入 $W_g$ 和 $W_u$；前者经过 SiLU 后与后者逐元素乘，再经 $W_d$ 投影回模型维度。

## [[../06-注意力与Transformer/07-完整 Transformer 积木|07-完整 Transformer 积木]]

1. 与上一节第 4 题相同：Norm→Attention→残差，再 Norm→FFN→残差。
2. 输入 `[B,T,D]=[2,128,768]`，12 头每头 64，Q 形状通常为 `[2,12,128,64]`。
3. 残差执行逐元素相加，两个张量必须形状一致，因此子层最终输出维度要回到 $D$。
4. 训练时所有真实 token 已知，可并行计算；生成时第 $t+1$ 步依赖刚生成的第 $t$ 个 token，不能完全同时产生。

## [[../06-注意力与Transformer/08-Decoder-Only 架构|08-Decoder-Only 架构]]

1. 可见矩阵为下三角：第 1 行仅看 1；第 2 行看 1–2；第 3 行看 1–3；第 4 行看 1–4。禁止区填 $-\infty$，允许区填 0。
2. BERT 式双向编码器通常可看左右全部非 padding token；GPT 式因果解码器只能看当前位置及左侧。
3. 可把类别写成目标 token 生成，或取特定位置隐藏状态接分类头；架构不限制输出只能是长文本。
4. 上下文学习只在输入提示中放示例，不改参数；微调通过训练更新全部或部分参数，效果可持久保存。

## [[../06-注意力与Transformer/09-注意力变体：GQA 与 MQA|09-GQA 与 MQA]]

1. $32/8=4$ 个 Query 头共享一组 KV 头。
2. 新 Query 只对应当前待生成位置；历史位置的 K/V 每一步都会被当前 Query 使用，因此缓存可避免重复投影历史 token。
3. 在层数、头维度和上下文相同时：MHA 最大，GQA 居中，MQA 最小。
4. 总延迟还包括矩阵计算、调度、通信、采样和其他内存访问；缓存可能不是唯一瓶颈，缩小容量也不等于带宽或吞吐同比改善。

## [[../06-注意力与Transformer/10-稠密模型与 MoE|10-稠密模型与 MoE]]

1. 稠密模型每个 token 使用一层的全部参数；MoE 由路由器为 token 选择少数专家，因此总参数多但单 token 激活参数较少。
2. 总参数影响存储和容量；激活参数更直接影响单 token 的主要计算量，二者不能混报。
3. 大多数 token 挤到少数专家，造成负载不均、专家训练不足、容量溢出和通信等待。
4. 专家分布在不同设备时，token 必须按路由跨设备发送再汇总；通信和负载不均会吞掉稀疏计算收益。
