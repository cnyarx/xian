# 本地部署

## 为什么本地运行

- 当模型权重、推理服务、工具和数据源都在本机，且未启用云端能力时，输入数据可以不离开本机；仍需检查遥测、自动更新和外部插件。遥测（telemetry）是软件自动向开发商发送使用情况、性能或错误等数据的机制。
- 没有按次 API 费用，但仍有电力、硬件和维护成本。
- 权重已合法下载并缓存后，可在工具和模型均支持的条件下离线使用和实验。

代价是硬件、安装、性能和安全都由自己负责。

## 硬件粗估

权重内存下限约：

$$\text{参数量}\times\text{每参数字节}$$

7B 模型 4-bit 权重理论约 3.5 GB，但还需要量化元数据、KV cache、运行时工作区和系统内存，实际需求更高。

## llama.cpp

llama.cpp 是以 C/C++ 实现的推理项目，支持 CPU、GPU 和 GGUF 文件。具体支持的模型架构和量化类型以当前仓库文档为准。

## Ollama

Ollama 在本地管理模型下载、模板和服务，通常更易上手；底层能力和支持平台应查官方文档。

## 安全

- 只下载可追溯到官方发布者的权重。
- 阅读模型许可证。
- 校验文件哈希。
- 服务默认不要暴露到公网。
- 不把隐私数据发送给不受信任模型或插件。

## 选择模型

考虑任务、语言、上下文、许可证、硬件、量化、工具调用和实测质量。参数量只是一个因素，不等同于能力。
