# 大模型学习教程：从基础到完整实践

## 这是什么

这是一套从基本算术、简单方程和坐标表示开始，完整学习大语言模型（Large Language Model，简称 LLM）的教程。

不要求你之前学过大学数学、编程或机器学习。专业概念会先在正文就地解释；需要独立复用的核心概念和公式会链接到概念词典与公式手册，并继续列出前置依赖。局部变量、普通词和两三句话即可说明的内容不会机械拆成文件，以免阅读变成链接迷宫。

## 适合怎样使用

- 对人工智能感兴趣，想知道大模型到底怎么工作；
- 想要系统学习大模型，但被各种术语和公式劝退；
- 已经会用 ChatGPT、Qwen 等工具，但想理解背后原理。

## 核心原则

### 1. 递归解释，保持连续阅读

教程会在专业概念首次出现时尽量就地解释；73 篇理论教程均设有“概念与公式导航”，可直接进入对应的独立概念页与公式页。概念词典现有 61 个独立原子页，依赖深度为 L0–L11；公式手册现有 26 个独立公式页。局部变量、别名以及两三句话即可说明的词在正文就近解释，不机械拆成独立文件，以免形成必须连续跳转的链接迷宫。

### 2. 有例子，有练习

理论教程包含例子和练习；73 篇理论教程的参考答案都在练习答案目录中。动手项目章节让你实际运行代码、观察结果。

### 3. 事实和推测分开

教程使用以下证据等级标注来源和需要区分证据强度的内容：

- **A**：权威来源（教材、原始论文、官方文档）
- **B**：论文推断（有论文支持但不是官方确认）
- **C**：社区实践（广泛使用但非正式发表）
- **U**：未知（截至修订日期没有可靠公开信息）

详见[[00-导读/证据与引用规范|证据与引用规范]]。

### 4. 中英文对照

教程反复使用、需要独立复用的核心概念会标注对应英文术语；正文中的其他专业词也会尽量在首次使用附近给出中英文对照，方便阅读论文和英文资料。
