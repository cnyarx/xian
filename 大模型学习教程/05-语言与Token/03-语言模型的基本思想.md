# 语言模型的基本思想

## 一句话定义

语言模型为 token 序列分配概率。自回归语言模型根据前面的 token，逐个预测下一个 token。

## 条件概率

给定序列 $x_1,x_2,\ldots,x_T$，联合概率可用概率链式法则分解：

$$P(x_1,\ldots,x_T)=\prod_{t=1}^{T}P(x_t\mid x_1,\ldots,x_{t-1})$$

- $x_t$：第 $t$ 个 token。
- 竖线 `|`：在已知右侧条件时。
- $\prod$：把各项相乘。

这表示：整句话的概率等于每个 token 在前文条件下出现概率的乘积。

## 下一个 token 预测

训练文本：

```text
我 喜欢 学习 人工 智能
```

可以同时构造多个训练位置：

```text
输入：我                  目标：喜欢
输入：我 喜欢             目标：学习
输入：我 喜欢 学习        目标：人工
输入：我 喜欢 学习 人工   目标：智能
```

实际训练通过一次并行前向传播计算所有位置，但因果掩码保证每个位置看不到未来答案。

## 自回归生成

```text
提示：今天天气
模型预测：很好（概率最高或被采样）
新输入：今天天气很好
模型预测：，
新输入：今天天气很好，
模型预测：适合
...
```

每次把新 token 追加到上下文，再预测下一个，这叫自回归（Autoregressive）。

## 训练目标

对正确 token 的负对数概率求和：

$$L=-\sum_{t=1}^{T}\log P_\theta(x_t\mid x_{<t})$$

- $\theta$：模型全部参数。
- $x_{<t}$：位置 $t$ 之前的 token。
- 让 $L$ 下降，就是提高真实下一个 token 的概率。

## 为什么简单目标能学到复杂能力

为了准确预测下一个 token，模型必须从数据中捕捉语法、词义、事实共现、文本结构和部分推理模式。但“预测目标要求利用这些规律”不等于模型拥有与人相同的理解、意识或可靠世界模型；这些更强主张需要独立证据。

## 常见误区

- 语言模型不是只记下一个词；它使用整个可见上下文估计分布。
- 生成概率高不等于事实正确，只表示在模型学到的分布下更可能。
- 训练通常可并行，生成通常逐 token 进行。
