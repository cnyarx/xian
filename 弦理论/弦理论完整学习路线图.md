# 弦理论完整学习路线图

> [!abstract] 这套课程要解决什么
> 从普通高中数学、物理起点出发，逐步学会标准临界微扰超弦理论（standard critical perturbative superstring theory），并能够继续学习 D-brane、紧致化、对偶关系和 M 理论导论。每个具体概念独立成一篇 Markdown 教程；本文件只负责给出路线、依赖关系和验收标准。

## 如何使用这套知识库

1. 按阶段顺序学习，不必一开始读研究生教材。
2. 遇到 `[[双链]]` 时，可以打开对应概念文件补前置知识。
3. 每篇概念教程都应包含：中英文名、直观解释、正式定义、公式解释、例子、练习、答案提示、常见误区、用途和来源。
4. “理解”不是背结论，而是能用自己的话解释、完成基础计算并知道结论的适用条件。
5. 对偶关系、M 理论等非微扰内容必须标明证据地位，不能把强证据支持的研究框架写成已普遍证明的定理。

详细规范见 [[弦理论教程写作与证据规范]]。

---

## 最终能力目标

完成核心课程后，应当能够：

1. 从 [[弦理论/物理学/相对论点粒子]] 过渡到 [[弦理论/物理学/Nambu-Goto 作用量]] 和 [[弦理论/物理学/Polyakov 作用量]]；
2. 推导 [[弦理论/物理学/开弦边界条件]]、[[弦理论/物理学/闭弦周期条件]] 和开闭弦的 [[弦理论/物理学/弦的模展开]]；
3. 理解 [[弦理论/物理学/世界面微分同胚]]、[[弦理论/物理学/Weyl 对称性]]、[[弦理论/物理学/共形规范]] 和 [[弦理论/物理学/Virasoro 约束]]；
4. 用 [[弦理论/数学/复分析]]、[[弦理论/物理学/算符乘积展开]]、[[弦理论/物理学/Virasoro 代数]] 和 [[弦理论/数学/中心荷]] 描述二维共形场论；
5. 理解 [[弦理论/物理学/规范固定]]、[[弦理论/物理学/Faddeev-Popov 鬼场]]、[[弦理论/物理学/BRST 对称性]] 与 [[弦理论/物理学/BRST 上同调]]；
6. 推导玻色弦临界维数 $D=26$ 和 RNS 超弦临界维数 $D=10$；
7. 理解 [[弦理论/物理学/NS 扇区]]、[[弦理论/物理学/R 扇区]]、[[弦理论/物理学/GSO 投影]] 与 [[弦理论/物理学/五种十维超弦理论]]；
8. 使用 [[弦理论/物理学/顶点算符]] 描述弦态，并理解树级 [[弦理论/物理学/弦散射振幅]]；
9. 理解 [[弦理论/物理学/T 对偶]]、[[弦理论/物理学/D-brane]]、[[弦理论/物理学/Chan-Paton 因子]] 和基础紧致化；
10. 准确区分：教材事实、低能有效近似、强证据支持的对偶关系和仍未完成的理论框架。

### 认识论边界

- 自由圆周 T 对偶可以从世界面 CFT 直接推导，是标准确立结果。
- DBI/WZ、超引力和 Calabi–Yau 大体积几何描述属于低能或参数受控的有效描述。
- S/U 对偶和 IIA 强耦合十一维关系有大量独立证据支持，但通常不应说成已对任意背景完成数学证明。
- M 理论尚没有适用于任意背景的公认统一完整定义；十一维超引力只是其低能极限，不等于完整 M 理论。

# 教材顺序

1. Barton Zwiebach, *A First Course in String Theory*, 2nd ed.：第一次接触弦论，直观且适合本科程度。
2. David Tong, *Lectures on String Theory*：免费研究生讲义，进入世界面和共形场论主线。
3. Joseph Polchinski, *String Theory*, Vol. 1：玻色弦、CFT、BRST 和振幅。
4. Joseph Polchinski, *String Theory*, Vol. 2：超弦、D-brane、紧致化和对偶。
5. Green, Schwarz, Witten, *Superstring Theory*, Vol. 1–2：经典技术体系和反常。
6. Becker, Becker, Schwarz, *String Theory and M-Theory*：现代综合复习与高级扩展。
