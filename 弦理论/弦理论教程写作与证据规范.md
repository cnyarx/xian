# 弦理论教程写作与证据规范

## 一、文件粒度

1. 每个具体概念独立放在一个 Markdown 文件中。
2. `数学/`、`物理学/` 只承担分类作用，不创建与目录同名的汇总页。
3. 一个文件只回答一个主要问题。例如“导数”和“积分”分别建文件；“Nambu–Goto 作用量”和“Polyakov 作用量”分别建文件。
4. 路线图、完整推导和专题综述可以保留为专题文件，但不能代替概念教程。
5. 跨学科概念只设置一个主文件，在其他文件中通过 Obsidian `[[双链]]` 引用。

## 二、每篇概念教程的固定结构

```markdown
---
aliases:
  - English Name
  - 中文别名
tags:
  - 学科
  - 层级
english_name: English Name
prerequisites:
  - "[[前置概念]]"
used_by:
  - "[[后续概念]]"
evidence_status: 教材事实 / 低能有效 / 强证据支持 / 开放问题
---

# 中文概念名（English Name）

## 一句话解释
## 为什么要学它
## 直观图景
## 正式定义
## 核心公式
## 公式中每个符号的意思
## 推导或理由
## 具体例子
## 常见误区
## 练习
## 答案与提示
## 与其他概念的关系
## 参考资料
```

允许按内容增加章节，但不能删除“核心公式解释”“练习”“答案提示”和“参考资料”。

## 三、语言标准

- 以普通高中阶段的代数、函数、基础力学为默认起点。
- 新术语第一次出现时给出中文名、英文名和一句话解释。
- 句子尽量短，先说直观图景，再给正式定义。
- 类比只能帮助理解，必须说明类比在哪里会失效。
- 不在成品中写“高中生版”“小白版”等受众分级标签。
- 不使用“显然”“易得”“不难看出”跳过关键推理。

## 四、公式规范

每个重要公式后必须依次回答：

1. 公式整体在说什么；
2. 每个符号表示什么；
3. 量纲是否一致；
4. 在什么条件下成立；
5. 能否给出一个代入数字或简单函数的例子；
6. 推导依赖哪些前置概念。

例如：

$$
T=\frac{1}{2\pi\alpha'}
$$

这条公式表示弦张力 $T$ 与 Regge 斜率参数 $\alpha'$ 成反比。$T$ 越大，弦越难被拉长。采用 $\hbar=c=1$ 的自然单位时，$\alpha'$ 具有长度平方的量纲。

不能只写公式，不解释成立条件和符号。

## 五、递归闭合规则

每完成一篇文件，执行以下检查：

1. 提取正文第一次出现的全部专业概念；
2. 判断普通高中基础能否直接理解；
3. 不能直接理解且对主结论必要的概念，必须建立独立文件；
4. 概念文件再次执行相同检查；
5. 递归在以下条件之一停止：
   - 已经是高中课程中的常用概念；
   - 本文件中已用高中知识完整定义和举例；
   - 只是非必要延伸，已明确标记为“可选扩展”。

禁止用无限增加同义词文件制造表面闭合。判断标准是能否理解和使用，而不是每个名词是否都有文件。

## 六、证据等级

### A：标准教材事实

可由标准教材、公开大学讲义或经典论文直接支持，并且成立条件明确。例如：

- Polyakov 作用量的经典 Weyl 对称性；
- Virasoro 代数；
- 临界玻色弦 $D=26$；
- 临界 RNS 超弦 $D=10$；
- 自由圆周 CFT 的 T 对偶。

### B：受控近似或低能有效描述

在特定能量、耦合、曲率或导数展开条件下可靠。例如：

- DBI 作用量；
- 十维超引力；
- Calabi–Yau 大体积几何描述；
- sigma-model beta 函数的低阶 $\alpha'$ 展开。

必须写明近似参数和适用范围。

### C：强证据支持的关系

拥有谱、BPS 态、反常、荷格或低能作用量等多类一致证据，但不应说成已对任意背景完成严格数学证明。例如：

- Type IIB 的 $SL(2,\mathbb Z)$ S 对偶；
- Type I 与 $SO(32)$ 杂化弦的对偶；
- Type IIA 强耦合出现十一维极限；
- U 对偶网络。

### U：开放问题或尚无完整定义

例如：

- 任意背景下的统一完整 M 理论定义；
- 所有弦真空的完整分类；
- 唯一选择出现实宇宙真空的原理。

必须明确写“未知”“尚未完成”或“研究中的猜想”，不能补写成事实。

## 七、来源优先级

1. 标准教材和作者公开讲义；
2. 同行评议经典论文；
3. arXiv 上由领域专家撰写的课程讲义或综述；
4. 大学公开课程；
5. 其他二手资料只能辅助理解，不能成为关键物理结论的唯一证据。

每篇至少列出一项可核验来源；高级或有争议内容至少列出两项独立来源。

## 九、练习设计

每篇至少包含三类练习：

1. **复述题**：用自己的话解释概念；
2. **计算题**：代入数字、推导简单情况或检验公式；
3. **辨析题**：判断常见说法为何正确或错误。

答案应给出步骤或关键提示，不能只有最终数字。

## 十、完成验收

单篇文件只有同时满足以下条件才视为完成：

- 标题含中英文名；
- YAML 中列出英文别名、先修和用途；
- 至少一个直观例子；
- 所有重要公式有逐符号解释；
- 至少三道练习及答案提示；
- 至少一项权威来源；
- 没有指向不存在文件的双链；
- 新出现的必要概念已递归闭合；
- 事实地位和适用范围标注准确。

整个课程只有在 [[弦理论完整学习路线图]] 中所有核心节点都有对应文件，并且自动检查不存在断链、空教程和无来源教程时，才视为完成。
