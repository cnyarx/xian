# 弦理论与大模型知识库

这是一个**扁平化**的 Obsidian 知识库：弦理论、数学、物理学与大模型（LLM）的全部文档都放在同一层级，不再有学科子目录。学科领域用 **tag** 区分，概念之间用 **链接** 交叉，相同概念**合并为同一页**，从而做到“交叉而不重复”。

> [!info] 为什么取消子目录
> 目录树会把同一个概念在“弦理论/数学/大模型”里割裂成多份，既重复又阻碍交叉。扁平结构下，一个概念只有一页，链接按**唯一文件名**解析（文件名不带数字前缀，避免影响 Obsidian 识别），学科归属完全交给 tag。唯一保留的子目录是 `handoffs/`（工作交接记录，不属于知识库正文）。

## 核心原则：证据与边界

本库坚持“事实、论文和公式有可靠来源，不编造结论；类比必须说明边界”。

- **证据分级**：`A` 权威来源（教材、原始论文、官方文档）· `B` 论文推断（有论文支持但非官方确认）· `C` 社区实践（广泛使用但非正式发表）· `U` 未知（截至修订日期无可靠公开信息）。
- **事实与推测分开**：跨学科类比、方向性猜想、史实再诠释都需显式标注证据强度，不把推断改写成事实。
- **禁止误连**：形似而实非的概念（如正则化 ≠ 重整化、总参数 ≠ 激活参数、宣称上下文 ≠ 可靠上下文）单列边界，不建立虚假等价。
- **中英文对照**：反复使用、需独立复用的核心概念标注英文术语，便于查阅论文。
