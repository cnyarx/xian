# 模型量化与部署

## 量化

用更少位数保存权重、激活或 KV cache，从而减少显存占用、带宽压力和推理成本。

档案必须记录：官方或第三方、来源 checkpoint、量化方法、权重/激活/KV cache 位宽、group size、校准数据和精度变化。

常见部署制品包括 GPTQ、AWQ、GGUF，但量化制品不是新的基础模型系列。

## 性能口径

任何速度数字都必须同时记录：

- 硬件和 GPU 数量；
- 推理引擎及版本；
- 权重和激活精度；
- 输入长度、输出长度和并发；
- TTFT、单 token 延迟或吞吐量。

不同硬件、精度、引擎和并发条件下的数字不能直接比较。

## 与张量压缩的关系

量化、剪枝、低秩分解和知识蒸馏都可以视为减少计算或存储成本的方法，但它们保留的信息、误差来源和硬件收益不同。相关数学基础见 [[数学/张量与张量网络]]。
