# 大语言模型

大语言模型是使用大量文本或多模态数据训练、能够根据上下文生成或理解内容的神经网络模型。本文档库重点关注其算法、训练、验证和部署方法，不把模型内部结构直接解释成真实物理对象。

## 基本表示

模型把 token 映射成高维向量，在多层网络中进行张量计算，最后输出下一个 token 的概率分布。相关数学基础见 [[数学/高维表示]] 和 [[数学/张量与张量网络]]。

## 训练阶段

- [[计算机学/预训练与后训练]]：学习语言规律，再学习指令、偏好和推理行为；
- [[计算机学/长上下文]]：处理远超普通输入长度的内容；
- [[计算机学/模型量化与部署]]：把模型变成更节省资源的部署制品。
