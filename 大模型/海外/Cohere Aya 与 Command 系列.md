# Cohere Aya 与 Command 系列

## 主要开放权重

| 系列 | 代表版本 | 参数 | 上下文/能力 |
|---|---|---:|---|
| Aya | Aya 101、Aya 23 8B/35B、Aya Expanse 8B/32B | 8B–35B | 多语言 |
| Aya Vision | 8B、32B | 版本依模型卡 | 多语言视觉 |
| Command R | R、R+、R7B | 7B–104B | 128K、RAG、工具调用 |
| Command A+ | 05-2026 | 218B/24B | 官方上下文未披露 |

## 许可证与开放边界

许可证必须按 checkpoint 核对：既有 Apache 2.0，也有 CC-BY-NC-4.0 或研究限制。官方 Hugging Face 权重不等于所有产品 API 型号都开放。Command A Vision、Translate、Reasoning 等无可确认权重的型号不纳入主清单。
