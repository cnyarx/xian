# 开放权重大模型档案库

> [!info] 知识导航
> 分类：`计算机学/`  
> 核心概念：[[开放权重模型]] · [[预训练与后训练]] · [[稠密模型与稀疏专家模型]] · [[长上下文]] · [[模型量化与部署]]

## 目标

本目录持续记录国内外正式发布、能够公开下载权重的大模型系列，用于：

- 学习模型架构和训练方法；
- 比较不同模型的技术路线；
- 进行部署和选型；
- 追踪开放权重生态的发展；
- 为后续算法和方法论研究提供可核验资料。

## 收录口径

### 收录

- 官方正式发布；
- 可以从官方仓库、官方模型组织或官方指定平台下载权重；
- 有能够确认模型身份和版本的官方资料；
- 许可证允许至少某种形式的本地使用。

### 不进入主清单

- 只有 API、不能下载权重的闭源模型；
- 尚未正式发布的传闻型号；
- 名称存在歧义且找不到官方证据的型号；
- 只有社区复刻、没有官方权重的同名模型；
- 仅有量化文件但无法追溯来源权重的模型。

这些内容统一记录在 [[大模型/待确认/待确认与未开放模型|待确认与未开放模型]] 中。

## 档案粒度

每个正式模型系列一篇文档。例如：

- Qwen3 系列一篇；
- DeepSeek-V3 系列一篇；
- Llama 4 系列一篇。

同一篇中分别记录：

- Base、Pretrained；
- Instruct、Chat；
- Reasoning；
- 不同参数规模；
- 官方长上下文版本；
- 官方量化制品。

第三方量化版不算新的模型系列，也不能把量化方法写成基础模型的训练方法。

## 证据等级

每个重要字段单独标记证据：

- **A：官方披露**——官方论文、技术报告、模型卡、仓库、配置或公告；
- **B：论文推断**——独立论文或可重复分析得出的推断，官方未确认；
- **C：社区复现**——有代码、环境和结果的公开复现；
- **U：未知**——截至档案修订日期未找到可靠证据。

详细规则见 [[大模型/方法论/证据与术语规范|大模型档案证据与术语规范]]。

## 每篇档案包含什么

1. 身份、版本和许可证；
2. 官方权重和主要变体；
3. 架构与参数规模；
4. Dense/MoE 和激活参数；
5. 注意力、位置编码和上下文；
6. Tokenizer；
7. 预训练目标、token 数和数据方法；
8. Continued pretraining 与课程学习；
9. SFT、偏好优化和强化学习；
10. 合成数据、蒸馏和推理训练；
11. 工具调用与多模态；
12. 量化与部署；
13. 评测、能力与局限；
14. 未公开信息；
15. 官方资料、论文和社区复现链接；
16. 修订记录。

## 阅读注意事项

- “开放权重”不等于完整开源：训练数据、训练代码和训练过程可能没有公开。
- 官方宣称的上下文长度不等于社区能够稳定利用的长度。
- 总参数量和每个 token 激活参数量必须分开记录。
- Base 版的训练方法不能自动套用给 Instruct 或 Reasoning 版。
- 官方 API 产品和公开权重可能不是同一个模型版本。
- “官方未披露”不等于“没有使用”。
