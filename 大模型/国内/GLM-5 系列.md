# GLM-5 系列

## 身份

智谱/Z.ai 官方仓库列出 `GLM-5`、`GLM-5.1`、`GLM-5.2`、`GLM-5.3` 以及 Flash、BF16、FP8 等变体，并提供 Hugging Face 和 ModelScope 权重入口。

用户原始名称 `glt-5.x` 没有官方证据，不能直接改写成 GLM-5.x；本档案只是记录真实存在且开放权重的 GLM-5 系列。

## 许可证与开放边界

官方资料将 GLM-5.3 描述为 open-weights model。各版本参数、激活参数、上下文、架构、训练方法、量化和许可证应以对应 checkpoint 模型卡为准，不能由家族级描述自动套用。

## 未公开字段

完整训练数据、训练代码、训练 token 数、后训练轨迹、奖励模型和成本未统一公开。
