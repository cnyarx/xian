# 待确认与未开放模型

> [!warning] 收录边界
> 本页记录只有 API、尚未发布、名称存在歧义或尚未找到官方开放权重证据的型号。进入本页不代表型号一定存在，也不代表最终不会进入主档案库。

## 状态定义

- **待核验**：尚在查找官方来源；
- **名称歧义**：名称可能是误写、社区称呼或多个产品的混称；
- **未正式发布**：只有预告或传闻，没有正式模型发布；
- **仅 API**：官方提供调用接口，但未开放可下载权重；
- **无官方证据**：截至修订日期未找到官方可核验资料；
- **已转主档案**：后来确认有官方开放权重，已迁入国内或海外目录。

## 记录规则

1. 只使用官方公告、官方仓库、官方模型组织、官方技术报告或论文确认模型身份；
2. 搜索结果、媒体转述和社区讨论不能单独作为正式身份依据；
3. 没有权威证据时写“未确认”，不猜测型号对应关系；
4. 核实存在官方开放权重后，创建正式系列档案，并将本页状态改为“已转主档案”；
5. 如果只有 API，保留在本页并记录官方 API 产品页和版本边界。
